# AI Lead Capture & Qualification System

## Overview

An AI-powered lead capture workflow built with self-hosted n8n.

This workflow collects leads from a Tally form, analyzes each lead using OpenAI, stores the results in Google Sheets, and automatically sends a personalized follow-up email.

## Workflow

Tally Form
↓
Webhook
↓
Code (Transform Lead Data)
↓
Message a Model (OpenAI)
↓
Code (Parse AI JSON)
↓
Merge
↓
Google Sheets
↓
Gmail
